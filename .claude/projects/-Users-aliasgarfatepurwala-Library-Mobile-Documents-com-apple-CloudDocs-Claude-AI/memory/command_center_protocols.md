## PROTOCOL 1: PICTURE ANALYSIS FOR INTEGRATION

### Directive
Every picture the user sends is related to something that needs to be integrated or configured with Claude. It is my responsibility to extract what needs to be integrated.

### Process
**I DO NOT rely on user explanation.** Instead:

1. ✅ **Analyze the picture thoroughly**
   - Read text, diagrams, charts, specifications
   - Identify the specific technology/tool/system mentioned
   - Extract integration points and configuration requirements

2. ✅ **Evaluate the benefit for Claude**
   - How does this improve Claude's capabilities?
   - What new functionality does it enable?
   - Which of the 6 active projects benefit from this?

3. ✅ **Determine integration requirements**
   - What needs to be installed/configured?
   - What are dependencies?
   - How does it integrate with existing systems?

4. ✅ **Add to integration queue**
   - Categorize alongside other integrations
   - Calculate annual value impact
   - Recommend priority (1-5 stars)
   - Project into registry

5. ✅ **Report findings automatically**
   - Do NOT ask the user to explain
   - Present: "This picture shows [technology]. Benefits: [list]. Integration path: [steps]. Estimated annual value: [amount]."

### Key Principle
**The user should not have to explain what each picture represents.** I extract this automatically through careful analysis.

## PROTOCOL 2: SESSION MEMORY CONSOLIDATION

### Directive
When the user provides a link to a closed session's archive, I consolidate that entire session's knowledge into the Command Center.

### Process

1. ✅ **Read the archive file**
   - Extract complete transcript/documentation
   - Identify all projects, learnings, decisions

2. ✅ **Deduplicate against existing memory**
   - Compare against all existing memory files
   - Identify what's already known
   - Flag what's new/unique

3. ✅ **Extract new data only**
   - Exclude duplicates
   - Add new insights, metrics, configurations
   - Merge technical details

4. ✅ **Create archive memory file**
   - Structured memory document
   - Link to source archive
   - Include technical specifications, timelines, lessons learned

5. ✅ **Update MEMORY.md**
   - Link to new archive file
   - Update project status
   - Cross-reference related systems
